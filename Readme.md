# React – The Complete Guide (2025) 🚀

This repository contains my notes, exercises, and projects from **React – The Complete Guide (2025)** by **Academind** on Udemy. I’ve recently completed the course and consolidated everything here, from basics to advanced concepts—including Hooks, state management, authentication, Next.js, testing, and more.

## 📚 Course Overview

- Modern React fundamentals: JSX, Virtual DOM, components, props, and state
- React Hooks: `useState`, `useEffect`, `useContext`, custom hooks, and other built-in hooks
- Handling forms (controlled & uncontrolled), validation, and React Hook Form
- React Router: nested routes, route parameters, guards
- State management: Context API, Redux & Redux Toolkit
- HTTP requests with `fetch`/Axios, loading and error states
- Authentication & Authorization flows using JWT and protected routes
- Performance optimization: `memo`, `useMemo`, `useCallback`, and code splitting
- Styling: CSS Modules, Styled‑Components, Framer Motion for animations
- React Query (TanStack Query) for cache and data management
- Testing: Unit testing with Jest & React Testing Library
- Intro to Next.js: App Router, Server Components, SSR/SSG, file-based routing
- Deployment on Vercel and Netlify
- Best practices, design patterns, reusable component logic
